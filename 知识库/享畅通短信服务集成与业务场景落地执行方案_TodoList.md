# 享畅通短信服务集成与业务场景落地执行方案 (含 TodoList)

> 本方案针对“享宇AI智评”项目接入**享畅通短信网关（XCT SMS）**进行系统化落地设计与实施。方案严格对接已报备过审的固定短信签名与 4 大官方模版，实现了安全凭据配置、60秒防刷频控、5次输错防撞库锁定、一次性凭据消费防重放，并完成了四大核心业务场景的业务端点编排。

---

## 一、核心需求与方案确认总结

| 序号 | 核心问题 / 需求项 | 方案确认与实施方式 |
| :--- | :--- | :--- |
| **1** | **商户账号与密钥配置位置** | **双层纳管机制**：<br>1. 基础配置：写入后端 `backend/.env`（统一纳管单真理源），字段为 `XCT_SMS_NAME` 与 `XCT_SMS_KEY`；<br>2. 运营热配与诊断：提供后台管理接口 `GET /api/admin/settings/sms`（脱敏展示）、`POST /api/admin/settings/sms`（账号密钥签名一并热保存）与 `POST /api/admin/settings/sms/test`（连通性测试探针）。 |
| **2** | **短信签名抽取与协同配置** | **已抽取为配置，与商户账号密码一同统一纳管**：<br>1. 环境变量：`.env` 中配置 `XCT_SMS_SIGN="成都享宇森云科技"`（默认提供已报备签名，可随需调整）；<br>2. 管理后台：在管理后台与商户账号、密码一并展示并支持在线热更新；<br>3. 适配器机制：适配器动态读取生效配置，内置智能括号清洗（自动去除重复 `【】` 或 `[]` 并严格以 `【签名】` 格式化）。 |
| **3** | **复用已审核通过的标准模版** | **100% 逐字对齐报备模版**（见第三节）。涵盖 `login`、`register`、`change_pwd`、`reset_pwd` 四大模版。 |
| **4** | **按不同模版实现对应功能** | **四大业务通道全面就绪**：<br>1. 登录场景：`/api/v1/auth/login`<br>2. 注册场景：`/api/v1/auth/register`<br>3. 修改密码场景：`/api/v1/auth/change-password`<br>4. 找回/重置密码场景：`/api/v1/auth/reset-password` |

## 二、架构设计与安全控制机制

```
                                  +---------------------------------------+
                                  |         客户端 (Web / 移动端)         |
                                  +---------------------------------------+
                                           |                      ^
                 1. 请求发码 (/send-code)  |                      | 2. 返回无状态凭证 sms_token
                                           v                      |
+-------------------------------------------------------------------------+
|                         FastAPI 网关 & 业务控制层                         |
|  - 场景合法性校验 (login / register / change_pwd / reset_pwd)            |
|  - 生成 6 位真随机数字验证码                                             |
|  - 签发防篡改业务凭证 sms_token (UUIDv4)                                 |
+-------------------------------------------------------------------------+
                                           |
                                           v
+-------------------------------------------------------------------------+
|                        统一短信中台 (SMSService)                         |
|  1. 防刷频控拦截：                                                       |
|     - Redis 原子 Key: sms-rate-limit:{phone} (TTL: 60s)                 |
|     - 数据库降级检查: sms_logs 表中 60 秒内是否已有发码记录                 |
|  2. 模版正文组装: 【成都享宇森云科技】+ 对应场景报备模版                   |
|  3. 凭据与重试计数入库:                                                  |
|     - sms-code:{sms_token} -> 6位验证码 (TTL: 300s)                     |
|     - sms-code-valid-times:{sms_token} -> 输错计数器 (超5次强制作废)      |
|     - 兼容历史 key: sms-code:{phone}:{scene}                            |
|  4. 全量流水审计: 写入 sms_logs 存证表 (含耗时、入参、出参、IP)            |
+-------------------------------------------------------------------------+
       |                                                   |
       | 开发/测试环境 (XCT_SMS_IS_OPEN=False)             | 生产正式环境 (XCT_SMS_IS_OPEN=True)
       v                                                   v
+-----------------------------+        +----------------------------------+
|      挡板拦截器 (Mock)       |        |      享畅通官方短信网关           |
|  - 拟真发送成功返回          |        |  - 请求方式: HTTP GET            |
|  - 零短信资费消耗            |        |  - 时间戳盐: yyyyMMddHHmmss (seed) |
|  - 打印详细模拟报文          |        |  - 鉴权签名: MD5(MD5(key)+seed)  |
+-----------------------------+        |  - 文本编码: UTF-8 URL Encode    |
                                       +----------------------------------+
```

## 三、官方审核通过的 4 大模版规范

| 场景代码 (`scene`) | 业务功能对应 | 审核通过的模版原文 (代码内置占位符 `{code}`) |
| :--- | :--- | :--- |
| `login` | 用户登录 | `【成都享宇森云科技】您正在进行登录操作，验证码为：{code}，5分钟内有效，请勿向他人泄露。如非本人操作，请忽略！` |
| `register` | 账号注册 | `【成都享宇森云科技】您正在进行注册账号操作，验证码为：{code}，5分钟内有效，请勿向他人泄露。如非本人操作，请忽略！` |
| `change_pwd` | 个人中心改密 | `【成都享宇森云科技】您正在进行修改密码操作，验证码为：{code}，5分钟内有效，请勿向他人泄露。如非本人操作，请忽略！` |
| `reset_pwd` | 找回/重置密码 | `【成都享宇森云科技】您正在进行找回密码操作，验证码为：{code}，5分钟内有效，请勿向他人泄露。如非本人操作，请忽略！` |

## 五、生产上线前运维切换指南 (Go-Live Runbook)

当需要将享畅通短信从开发挡板模式切换为生产正式网络外发时，执行以下步骤：

1. **配置生产凭据**：
   在生产服务器的 `backend/.env` 中填入享畅通分配的真实账号与密钥：
   ```ini
   SMS_PROVIDER="xct"
   XCT_SMS_URL="http://api.xct.com/sms/send" # 或服务商提供的生产地址
   XCT_SMS_NAME="真实商户账号"
   XCT_SMS_KEY="真实商户密钥"
   XCT_SMS_SIGN="成都享宇森云科技"
   XCT_SMS_IS_OPEN=true                      # 切换为 true 开启真实扣费发送
   ```

2. **管理后台连通性自检**：
   登录 Admin 管理后台，进入【系统设置】->【短信网关】，向测试手机号触发一次测试短信。
   观察网关返回值是否包含 `success`，并确认手机真实收到前缀为 `【成都享宇森云科技】` 的验证码。

3. **对账与排查**：
   所有发送流水均可在 MySQL 的 `sms_logs` 表中进行溯源核对，包含状态（`sent` / `verified` / `failed`）、IP 地址、网关响应报文及核验时间戳。
